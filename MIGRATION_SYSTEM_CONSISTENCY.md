### **PHASE 4.3A: Eliminate Hardcoded Type Lists** (1-2 hours)

#### **Task A1: Replace Primitive Type Detection**
**File:** `src/auto_migration/analyzer.rs:271-277`

**Problem:** Hardcoded primitive type matching violates zero-hardcoded-types policy

**Solution:** Implement trait-based type classification system
```rust
// BEFORE (VIOLATION):
pub fn is_primitive_type(&self, type_name: &str) -> bool {
    matches!(type_name, "i8" | "i16" | "i32" | ...)
}

// AFTER (TYPE-SAFE):
pub trait SqlTypeMappable {
    fn sql_type() -> &'static str;
    fn is_primitive() -> bool;
    fn is_numeric() -> bool;
    fn is_text() -> bool;
}

// Auto-implement for standard types via macro
impl_sql_type_mappable! {
    i8, i16, i32, i64, i128, isize => ("INTEGER", true, true, false),
    u8, u16, u32, u64, u128, usize => ("INTEGER", true, true, false),
    f32, f64 => ("REAL", true, true, false),
    bool => ("INTEGER", true, false, false), // Special boolean handling
    String, &str => ("TEXT", true, false, true),
}

pub fn is_primitive_type<T: SqlTypeMappable>() -> bool {
    T::is_primitive()
}
```

**Implementation Steps:**
1. Create `SqlTypeMappable` trait in `src/types.rs`
2. Implement macro `impl_sql_type_mappable!` for automatic trait implementation
3. Replace string-based type detection with trait-based detection
4. Update analyzer to use generic trait methods instead of string matching
5. Allow users to extend type mappings for custom types

**Testing:** Ensure all existing tests pass with new trait-based detection

### **PHASE 4.3B: Type-Safe Migration API** (3-4 hours)

#### **Task B1: Create Compile-Time Safe Migration Builders**

**Problem:** Current migration API uses string literals that can have typos

**Current (VIOLATION):**

**Target (TYPE-SAFE):**

**Solution:** Generate type-safe migration builders via derive macro

**Implementation:**

1. **Extend Entity derive macro** to generate column types:
```rust
// Generated by #[derive(Entity)] for User struct
impl User {
    pub fn name() -> UserNameColumn { UserNameColumn::new() }
    pub fn is_active() -> UserIsActiveColumn { UserIsActiveColumn::new() }
}

pub struct UserNameColumn {
    constraints: Vec<ColumnConstraint>,
}

impl TypeSafeColumn for UserNameColumn {
    type RustType = String;
    fn sql_type() -> &'static str { "TEXT" }
    fn column_name() -> &'static str { "name" }
}
```

2. **Create type-safe migration API:**
```rust
pub struct TypeSafeMigration<T: Entity> {
    table_name: &'static str,
    columns: Vec<Box<dyn TypeSafeColumnDef>>,
}

impl<T: Entity> TypeSafeMigration<T> {
    pub fn column<C: TypeSafeColumn>(mut self, _field: fn() -> C, column: C) -> Self {
        self.columns.push(Box::new(column));
        self
    }
}
```

3. **Generate macro for creating migrations:**
```rust

    table: User,
```

#### **Task B2: Connect Migrations to Entity Definitions**

**Problem:** No compile-time verification that migrations match Entity fields

**Solution:** Generate migrations automatically from Entity changes

```rust
    #[column(type = "TEXT", not_null)]

            .column(User::name, UserNameColumn::new().not_null())
            .column(User::is_active, UserIsActiveColumn::new().default(true))
    }
}
```
