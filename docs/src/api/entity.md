# Entity Trait API Reference

The `Entity` trait is the core trait that all database entities implement. It's typically implemented automatically via the `#[derive(Entity)]` macro.

## Trait Definition

```rust
pub trait Entity: 
    std::fmt::Debug + 
    serde::Serialize + 
    serde::de::DeserializeOwned + 
    Clone + 
    Send + 
    Sync + 
    'static 
{
    /// Builder for creating new instances
    type CreateBuilder: Send + Sync;
    
    /// Builder for updating existing instances  
    type UpdateBuilder: Send + Sync;
    
    /// Builder for querying instances
    type QueryBuilder: Send + Sync;
    
    // Required methods (typically generated by derive macro)
    fn table_name() -> &'static str;
    fn primary_key_field() -> &'static str;
    fn boolean_fields() -> Vec<&'static str>;
    fn from_row(row: Vec<(String, serde_json::Value)>) -> Result<Self>;
    fn to_values(&self) -> Vec<(String, serde_json::Value)>;
    fn get_primary_key_value(&self) -> serde_json::Value;
    
    // Default implementations provided
    fn create() -> Self::CreateBuilder { /* ... */ }
    fn update(id: impl Into<serde_json::Value>) -> Self::UpdateBuilder { /* ... */ }
    fn query() -> Self::QueryBuilder { /* ... */ }
    
    // CRUD operations
    async fn find(db: &D1Client, id: impl Into<serde_json::Value> + Send) -> Result<Option<Self>>;
    async fn delete(db: &D1Client, id: impl Into<serde_json::Value> + Send) -> Result<()>;
}
```

## Automatic Implementation

The trait is implemented automatically when you derive `Entity`:

```rust
use d1_rs::*;
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize, Clone, Entity, PartialEq)]
pub struct User {
    #[primary_key]
    pub id: i64,
    pub name: String,
    pub email: String,
    pub is_active: bool,
    pub created_at: DateTime<Utc>,
}
```

## Usage Examples

### Basic CRUD Operations

```rust
async fn crud_examples(db: &D1Client) -> Result<()> {
    // Create
    let user = User::create()
        .set_name("Alice Johnson".to_string())
        .set_email("alice@example.com".to_string())
        .set_is_active(true)
        .set_created_at(Utc::now())
        .save(db)
        .await?;
    
    println!("Created user with ID: {}", user.id);
    
    // Read
    let found_user = User::find(db, user.id).await?;
    match found_user {
        Some(u) => println!("Found user: {}", u.name),
        None => println!("User not found"),
    }
    
    // Update
    let updated_user = User::update(user.id)
        .set_name("Alice Smith".to_string())
        .set_is_active(false)
        .save(db)
        .await?;
    
    println!("Updated user name: {}", updated_user.name);
    
    // Delete
    User::delete(db, user.id).await?;
    println!("Deleted user");
    
    Ok(())
}
```

### Query Operations

```rust
async fn query_examples(db: &D1Client) -> Result<()> {
    // Simple queries
    let all_users = User::query().all(db).await?;
    let first_user = User::query().first(db).await?;
    let user_count = User::query().count(db).await?;
    
    // Filtered queries
    let active_users = User::query()
        .where_is_active_eq(true)
        .all(db)
        .await?;
    
    let alice_users = User::query()
        .where_name_contains("Alice")
        .all(db)
        .await?;
    
    // Ordered queries
    let sorted_users = User::query()
        .order_by_name_asc()
        .order_by_created_at_desc()
        .all(db)
        .await?;
    
    // Paginated queries
    let page_1 = User::query()
        .limit(10)
        .offset(0)
        .all(db)
        .await?;
    
    Ok(())
}
```

## Attributes

### Primary Key

```rust
#[derive(Entity)]
pub struct Product {
    #[primary_key]
    pub sku: String,  // String primary key
    pub name: String,
}

// Without explicit primary key, "id" field is used
#[derive(Entity)]
pub struct Category {
    pub id: i64,      // Automatically detected as primary key
    pub name: String,
}
```

### Table Name

```rust
#[derive(Entity)]
#[table(name = "custom_table_name")]
pub struct MyEntity {
    pub id: i64,
    // ...
}

// Without attribute, uses pluralized snake_case of struct name
#[derive(Entity)]
pub struct BlogPost {  // Uses "blog_posts" table
    pub id: i64,
    // ...
}
```

        .await
    {

        }

## Extending Entities

You can add custom methods to your entities:

```rust
#[derive(Entity)]
pub struct User {
    pub id: i64,
    pub name: String,
    pub email: String,
    pub is_active: bool,
}

impl User {
    // Custom query methods
    pub async fn find_by_email(db: &D1Client, email: &str) -> Result<Option<User>> {
        User::query()
            .where_email_eq(email.to_string())
            .first(db)
            .await
    }
    
    pub async fn active_users(db: &D1Client) -> Result<Vec<User>> {
        User::query()
            .where_is_active_eq(true)
            .order_by_name_asc()
            .all(db)
            .await
    }
    
    // Custom instance methods
    pub async fn deactivate(&self, db: &D1Client) -> Result<User> {
        User::update(self.id)
            .set_is_active(false)
            .save(db)
            .await
    }
    
    pub fn display_name(&self) -> String {
        if self.name.is_empty() {
            self.email.split('@').next().unwrap_or("Unknown").to_string()
        } else {
            self.name.clone()
        }
    }
}
```
